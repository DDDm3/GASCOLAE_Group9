## 2. Cấu trúc chi tiết của một dự án (`DU_AN_XX`)

```

├── assets/
│   ├── img/
│   └── video/

│   ├── 00_overview.md

```

## 3. Mô tả các thư mục

| Thư mục | Nội dung |
|---|---|
| `DU_AN_01` … `DU_AN_10` | 10 thư mục dự án, mỗi thư mục có cấu trúc giống nhau |
| `assets/` | Tài nguyên đa phương tiện của dự án |
| `assets/img/` | Hình ảnh (ảnh minh họa, sơ đồ, ảnh chụp màn hình, biểu đồ) |
| `assets/video/` | Video (demo, hướng dẫn, bản ghi màn hình) |
| `docs/` | Tài liệu của dự án, gồm các file từ `00` đến `04` |
| `code/` | Toàn bộ mã nguồn của dự án |
| `code/script/` | Các script hỗ trợ (cài đặt, xử lý dữ liệu, chạy tự động) |
| `code/src/` | Mã nguồn chính |
| `code/test/` | Mã kiểm thử (unit test, integration test) |

## 4. Các file tài liệu trong `docs/`

| File | Nội dung |
|---|---|
| `00_overview.md` | Tổng quan dự án: mục tiêu, phạm vi, thành viên |
| `01_requirements.md` | Phân tích yêu cầu |
| `02_design.md` | Thiết kế hệ thống / giải pháp |
| `03_implementation.md` | Triển khai, hướng dẫn cài đặt và chạy |
| `04_report.md` | Báo cáo kết quả, đánh giá và kết luận |

## 5. Quy ước

- Tên thư mục dự án theo mẫu `DU_AN_XX` (XX là số thứ tự hai chữ số, từ `01` đến `10`).
- Các file tài liệu đặt tên theo mẫu `NN_ten_tai_lieu.md`, đánh số từ `00` đến `04`.
- Ảnh lưu trong `assets/img/`, video lưu trong `assets/video/`; tài liệu tham chiếu đến chúng bằng đường dẫn tương đối.
