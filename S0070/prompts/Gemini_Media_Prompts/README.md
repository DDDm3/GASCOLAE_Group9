# Gemini Media Prompts

Generate the assets in numeric order. First approve the hero image, then use it as a visual reference for the remaining images and video.

Never upload real coordinates, site plans, restricted images, internal pricing or security information to an external generation service.

## Target set

- 8 still images or graphics
- 1 hero video
- 12–16 SVG icons should be created separately as exact vector assets, not generated as raster images
