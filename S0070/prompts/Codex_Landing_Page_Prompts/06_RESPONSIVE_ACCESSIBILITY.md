# Responsive and accessibility pass

```text
Perform a responsive and accessibility pass on the finished S0070 landing page.

Test at approximately 360, 390, 768, 1024, 1440 and 1920 pixel widths.

Verify:
- No horizontal overflow, clipped headings or overlapping media.
- Hero video is replaced or deferred on constrained mobile devices.
- Navigation works with keyboard and screen readers.
- Heading hierarchy is logical and contains one H1.
- Buttons and form fields have clear labels and visible focus states.
- FAQ accordion exposes correct expanded state.
- All meaningful images have concise alt text; decorative overlays are ignored.
- Color never carries meaning alone.
- Data visualization has an equivalent text explanation.
- Tap targets are at least 44 by 44 CSS pixels where practical.
- prefers-reduced-motion removes scanning, parallax and pulsing effects.
- Form errors are associated with fields and announced.

Fix all confirmed issues. Report any remaining limitation with exact reproduction steps.
```
