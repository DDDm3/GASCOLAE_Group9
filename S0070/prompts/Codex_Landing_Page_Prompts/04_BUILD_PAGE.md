# Build the landing page

```text
Build the complete S0070 landing page using the approved architecture, copy and design system.

Implementation requirements:
- Create a sticky header with section navigation and the primary CTA.
- Build a two-column hero with a media area that supports a poster image and optional muted looping video.
- Keep the left side of hero media visually quiet so copy remains readable.
- Build the three customer problems with typography and grid structure, not three generic cards.
- Create an accessible five-stage workflow.
- Present capabilities using meaningful data-oriented visuals.
- Build three service-level cards without a Most Popular badge.
- Present deliverables through an interface-style preview plus an accessible text list.
- Replace testimonials with a trust and limitations section.
- Build an accessible FAQ accordion.
- Add the S0070 Service Assistant placeholder or integration block.
- Build a minimal lead form that never requests coordinates or restricted details.
- Add a clear privacy and sensitive-information notice near the form.

Media paths should be centralized in a data/config file so generated assets can be replaced without editing components.

Use semantic HTML, progressive enhancement and reusable components. Preserve unrelated project code. Run the project and fix build or runtime errors before reporting completion.
```
