# Design system

```text
Define and implement a compact design system for the S0070 landing page.

Use the approved color tokens from the master context. Add only derived tones created from those tokens. Do not copy the Wix template palette or any ready-made palette.

Requirements:
- Establish semantic tokens for backgrounds, text, borders, action, focus, warning and data visualization.
- Ensure WCAG AA contrast for text and controls.
- Create a type scale, spacing scale, container widths, grid rules, radii, shadows and motion tokens.
- Use restrained borders and layered map-grid textures instead of repetitive floating cards.
- Define one primary button, one secondary button and one text link style.
- Define focus, hover, active, disabled and validation states.
- Support light data sections and dark narrative sections.
- Add prefers-reduced-motion and high-contrast considerations.
- Use SVG or CSS for exact interface decoration. Do not use AI-generated text inside images.

Return the token table and implement the design-system foundation in the project. Verify contrast values for the key foreground and background pairs.
```
