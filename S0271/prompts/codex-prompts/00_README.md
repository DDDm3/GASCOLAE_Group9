# S0271 — Codex Landing Page Prompt Pack

Mục tiêu: build landing page theo từng phần nhỏ, review được từng bước.

## Quy tắc chạy
- Không paste tất cả prompt cùng lúc.
- Chạy theo thứ tự file.
- Sau mỗi step: chạy app, kiểm tra, chỉnh nếu cần rồi mới sang step tiếp.
- Prompt sau giả định code của prompt trước đã tồn tại.

## Source/content rules
- File 09 là content specification.
- Không tự thêm giá, %, ROI, certification, timeline, client logos, testimonials.
- ppm không được trình bày như tCO₂e.
- Flux / CO₂e / collection efficiency phải giữ điều kiện.
- Không claim thay Method 21.
- Không claim phát hành carbon credit.
