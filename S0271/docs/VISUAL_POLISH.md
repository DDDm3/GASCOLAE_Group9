# Visual Polish

The final editorial pass reduces repeated UI treatment while preserving the approved palette, content, accessibility behavior and media loading strategy.

| Audit area | Finding | Change |
| --- | --- | --- |
| Repeated cards and shadows | Deliverable sheets read as generic elevated cards. | Removed the shadow and strengthened their physical overlap and alternating offsets. |
| Pills and rounded corners | Technology nodes and primary controls repeated the same soft shape. | Changed these elements to precise square corners; the floating Header retains its approved subtle radius. |
| Uniform rhythm | Most sections used the same vertical spacing and shared heading axis. | Introduced section-specific vertical pacing and grid-aligned heading offsets on large screens. |
| Centered composition | Technology and several section headings felt mechanically centered. | Shifted visual and heading anchors to the 12-column grid while retaining readable line lengths. |
| Media/text relationship | Before/After and Contact media sat independently from their copy. | Pulled Before/After media toward the copy axis and gave the Contact form a controlled overlap on desktop. |
| Predictable landscapes | Service Level panels appeared as three separated blocks. | Joined them into one cinematic sequence with a fine boundary between levels. |

No accent color, metric, testimonial, logo, content element, image request or dependency was added.
