Define a deliberate art direction for a scientific forest-carbon service.

Specify:
- visual concept
- typography
- type scale
- palette
- background treatment
- grid
- spacing rhythm
- cards
- buttons
- metric presentation
- GIS/map styling
- point-cloud styling
- 3D visual language
- image treatment
- section transitions
- hover behavior
- scroll behavior
- mobile composition
- loading/error states

Avoid generic 'green sustainability' aesthetics.
The page should visually connect forest ecology with remote sensing,
geospatial science and carbon measurement.

Do not start implementation yet.

GATE:
A developer should be able to implement the page without making major
visual decisions on their own.
