# PHASE 08 — MOTION & INTERACTION

Read AGENTS.md and the design/3D specs.

Use web-animation-design.

Add motion only where it improves comprehension:
- section reveal
- metric transitions
- process progression
- map layer transition
- 3D camera movement
- hover/focus feedback
- AI panel opening

Rules:
- prefer transform/opacity
- avoid layout-thrashing animation
- use sensible easing
- no scroll-jacking
- respect prefers-reduced-motion
- mobile motion must be lighter

GATE:
Motion communicates hierarchy/data transformation.
It must not compete with content.

STOP.
